# 한전 SRM 발전사 입찰공고 사이트

한국서부·남부·중부·남동·동서발전의 입찰공고를 한 화면에 모아서 보여주는 사이트입니다.

## 어떻게 동작하나요

1. 하루 3번(한국 시간 08:30, 12:30, 17:30 무렵) GitHub가 한전 전자입찰계약정보 API에서 공고를 받아 `data/bids.json`에 저장합니다.
2. 저장소가 바뀌면 Vercel이 사이트를 자동으로 다시 배포합니다.
3. 사이트는 `data/bids.json`을 읽어서 목록으로 보여줍니다.

## 폴더 구성

```
index.html                     화면 (검색, 기간, 발전사 선택, 공고 상세, ✕ 제외)
data/bids.json                 수집된 공고 (자동으로 갱신됨)
scripts/collect.mjs            API에서 공고를 받아오는 프로그램
.github/workflows/collect.yml  수집을 자동으로 돌리는 설정
```

## 처음 한 번만 하는 설정

### 1. GitHub 저장소 만들기
GitHub에 로그인해서 새 저장소를 만드세요. 이름은 자유롭게 정하면 되고(예: `kepco-bid`), 공개/비공개 중 편한 쪽을 고르세요. 인증키는 코드가 아니라 아래 3번의 Secrets에만 들어가므로 어느 쪽이든 노출되지 않습니다.

### 2. 파일 올리기
저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 `index.html`, `data`, `scripts`, `.github`를 끌어다 놓은 뒤 저장(커밋)하세요.

`.github` 폴더가 올라가지 않으면: **Add file → Create new file**을 누르고 파일 이름 칸에 `.github/workflows/collect.yml`을 입력한 다음, 이 폴더의 `collect.yml` 내용을 붙여넣고 저장하세요. (화면 표시는 조금 다를 수 있어요.)

### 3. 인증키 등록
저장소의 **Settings → Secrets and variables → Actions**로 들어가서 **Secrets** 탭의 **New repository secret**을 누르세요.

- Name: `KEPCO_API_KEY`
- Secret: 발급받은 인증키 (40자리)

인증키는 여기에만 입력하세요. 코드 파일이나 채팅에는 적지 마세요.

### 4. 수집 한 번 실행해보기
저장소의 **Actions** 탭에서 왼쪽 **공고 수집**을 고르고 **Run workflow**를 누르세요. 끝나면 `data/bids.json`이 공고로 채워집니다. 실패하면 실행 기록을 열어 **공고 수집** 단계의 메시지를 확인하세요. (인증키는 메시지에 나타나지 않도록 처리되어 있습니다.)

### 5. Vercel에 배포
vercel.com에 GitHub 계정으로 로그인한 뒤 **Add New → Project**에서 이 저장소를 가져오세요(Import). 설정은 다음처럼 합니다.

- Framework Preset: **Other**
- Build Command: 비워둠
- Output Directory: `.`

**Deploy**를 누르면 주소가 생깁니다. 이후에는 데이터가 갱신될 때마다 자동으로 다시 배포됩니다.

## 알아둘 점

- **마감일**은 입찰종료일시(개찰 전 최종 마감) 기준입니다.
- **✕로 제외한 공고**는 사용 중인 브라우저에 저장됩니다. 다른 기기와는 공유되지 않아요.
- 화면의 **검색** 버튼은 최신 데이터를 다시 불러옵니다. 데이터 자체는 하루 3번 갱신됩니다.
- 조회 범위(공고일 기준 과거 59일 ~ 미래 29일)와 마감 후 보관 기간(30일)은 `scripts/collect.mjs` 위쪽에서 바꿀 수 있습니다. API는 한 번에 최대 90일까지 조회됩니다.
- 참가자격 본문은 10,000자까지만 저장합니다.
- GitHub의 예약 실행은 정해진 시각보다 몇 분에서 수십 분 늦을 수 있습니다.

## 실제 데이터로 아직 확인하지 못한 것

- API가 한 번에 돌려줄 수 있는 건수에 제한이 있는지: 수집 로그에 "건수가 딱 떨어져요"라는 안내가 나오면 알려주세요.
- 공고가 없는 발전사를 조회했을 때 API가 어떻게 응답하는지: 오류로 응답하면 화면 위쪽에 "수집 실패"로 표시됩니다. 그 경우 로그 메시지를 알려주세요.
- 정정공고가 같은 공고번호로 올라오는지 새 번호로 올라오는지: ✕ 제외가 공고번호 기준이라 확인이 필요합니다.
- 첨부파일 링크가 로그인 없이 열리는지: 링크는 한전 SRM 서버 주소입니다.
